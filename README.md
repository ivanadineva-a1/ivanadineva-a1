## 👩🏻‍💻 About Me

Frontend Engineer specializing in video streaming platforms, real-time systems, and large-scale UI architecture, now also working in observability as part of the Cloud and Hybrid Infrastructure DC.

I work on frontend development end-to-end, from architecture to implementation, delivering production-grade platforms used at scale.

My work spans building admin dashboards and analytics-driven web applications, integrating third-party SDKs and AI-powered features, and automating data workflows to support engineering and reporting needs.

As an Observability Engineer, I build application performance monitoring solutions on Grafana, turning OpenTelemetry metrics, traces and alerts into clear insights into application health and performance.
